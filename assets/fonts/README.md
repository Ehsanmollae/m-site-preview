# فونت‌ها

فونت **استعداد (Estedad)** به‌صورت self-host استفاده می‌شود تا سایت به CDN خارجی
وابسته نباشد.

فقط یک فایل لازم است:

- `Estedad-VF.woff2` — نسخهٔ متغیر (variable)، حدود ۱۲۰ کیلوبایت

این یک فایل کل محور وزن را می‌آورد: `wght` از ۱۰۰ تا ۹۰۰. محور عرض ندارد، پس
سلسله‌مراتب تایپوگرافی با **وزن، اندازه و طول سطر** ساخته می‌شود، نه با عرض حروف.
اگر فایل نباشد، مرورگر به فونت سیستم (Segoe UI / Tahoma) برمی‌گردد و چیزی خراب
نمی‌شود، فقط تایپوگرافی ضعیف‌تر است.

وزن‌ها در `assets/css/theme.css` به‌صورت توکن تعریف شده‌اند:
`--w-display` (۸۰۰)، `--w-label` (۷۰۰)، `--w-body` (۴۰۰)، `--w-lead` (۳۰۰).

## فونت تیتر: امیری (Amiri)

- `Amiri-Regular.woff2` — حدود ۶۰ کیلوبایت

فقط برای نمایش: تیتر بزرگ صحنهٔ کمد، تیترهای پنل‌ها و لوگو. خط نسخ کلاسیک است و
در اندازهٔ خیلی بزرگ حس مجلهٔ مد می‌دهد. فایل اصلی حدود ۴۴۰ کیلوبایت بود؛ فقط حروف
فارسی، ارقام و لاتین پایه نگه داشته شده (subset با fontTools). لایسنس SIL OFL 1.1،
متن کامل در `Amiri-OFL.txt`. مخزن رسمی: https://github.com/aliftype/amiri

توکن: `--font-display` در `assets/css/theme.css`.

## لایسنس

استعداد تحت **SIL Open Font License 1.1** منتشر شده — رایگان و آزاد برای استفادهٔ
تجاری، بدون نیاز به خرید لایسنس.

مخزن رسمی: https://github.com/aminabedi68/Estedad
(در فایل فشردهٔ هر نسخه، فایل `Estedad[wght].woff2` را بردارید و با نام
`Estedad-VF.woff2` در همین پوشه بگذارید.)

## فونت‌هایی که استفاده نشدند

  محصول تجاری fontiran.com است و لایسنس وب جداگانه می‌خواهد.
- **وزیرمتن** — لایسنس آزاد دارد و گزینهٔ سالمی است، ولی عمداً خنثی طراحی شده و
  برای تیترهای درشت این صفحه شخصیت کافی ندارد. فایل‌هایش در تاریخچهٔ گیت هست.
